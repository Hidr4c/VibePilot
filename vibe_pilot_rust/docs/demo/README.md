# Demo GIF

Record your VibePilot demo here:

1. Download [LICEcap](https://www.cockos.com/licecap/) (free, lightweight)
2. Open LICEcap, select a region showing VibePilot
3. Click "Record" and run an automation profile
4. Save as `demo.gif` in this directory

The README will reference `docs/demo.gif`.

## Alternative tools

- [ScreenToGif](https://www.screentogif.com/) (Windows, free, open-source)
- [ShareX](https://getsharex.com/) (Windows, free, open-source)
- OBS Studio (for video recording)
